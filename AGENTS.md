# Олимпиадное программирование — занятия по алгоритмам и структурам данных

## Структура `themes/`

Каждая тема — отдельная папка в `themes/`, внутри ровно две подпапки:

```
themes/<название_темы>/
├── code/      # код с занятий — пишет пользователь
└── theory/
    └── theory.md   # конспект по теме — пишет Codex
```

- Название папки темы — по-английски, в нижнем регистре, слова через `_`: `linked_list`, `binary_search`, `stack_and_queue`.
- Когда пользователь пишет «новая тема: X», нужно создать `themes/<x>/code/` и `themes/<x>/theory/` и написать `theory/theory.md`.
- В `theory/` лежит **один** файл `theory.md` на тему.

## Правила

- **Код в `code/` без спроса не трогать**: не править, не переименовывать, не удалять. Замеченные ошибки — сообщать в чате или разбирать в конспекте (в разделе «Частые ошибки»), но не исправлять файлы. Писать новые файлы в `code/` можно только по прямой просьбе.
- Прежде чем писать или обновлять конспект, прочитать код темы в `code/`. Примеры из него можно использовать, ссылаясь на файл (`code/stack.py`); если в коде есть баг, в конспекте показывать исправленную версию и объяснять, что было не так.
- Все примеры кода в конспекте должны запускаться. Перед сдачей проверять их (Python вызывается через `py`, для кириллицы нужен `PYTHONIOENCODING=utf-8`).

## Формат `theory.md`

Писать по-русски, в стиле существующих конспектов (например, `themes/heap/theory/theory.md`):

1. `# Название (English name)`, сразу под ним `## Оглавление` — список ссылок на все разделы `##` и подразделы `###` (якоря в стиле GitHub: `[1. Что такое куча](#1-что-такое-куча)`), затем `---`. При добавлении или переименовании разделов оглавление обновлять.
2. Нумерованные разделы `## 1. ...`, подразделы `### 1.1. ...`, разделители `---` между разделами.
3. Сначала что это и зачем, с **аналогией** в блоке `>`; ASCII-схемы для структур.
4. Таблица операций/сложностей.
5. Реализация на Python с комментариями, затем стандартная библиотека (`heapq`, `collections.deque`, `sorted` ...).
6. «Типичные задачи» с кодом, упор на олимпиадные приёмы.
7. «Частые ошибки», «Шпаргалка», «Вопросы для самопроверки» с ответами в `<details>`.
8. Ссылки на связанные темы в виде `themes/<тема>/theory/theory.md`.
